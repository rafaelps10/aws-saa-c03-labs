# AWS Solutions Architect Associate — Hands-on Labs ☁️

Portfólio de projetos práticos desenvolvidos durante meus estudos para a certificação **AWS Certified Solutions Architect – Associate (SAA-C03)**.

O objetivo é aplicar conceitos de arquitetura em nuvem, segurança, redes, monitoramento e boas práticas da AWS, documentando a implementação e as decisões técnicas de cada projeto.

## 🎯 Objetivos

* Praticar a criação e configuração de recursos AWS.
* Compreender como os serviços se integram em uma arquitetura.
* Aplicar princípios de segurança e boas práticas.
* Documentar os projetos e registrar aprendizados.
* Construir um portfólio técnico para demonstrar minha evolução profissional em Cloud Computing.

## 📚 Projetos

### Projeto 01 — Infraestrutura de Rede Segura na AWS

**Status:** Planejamento

**Objetivo:** projetar uma infraestrutura de rede na AWS utilizando uma VPC com sub-redes públicas e privadas, distribuídas entre zonas de disponibilidade.

**Componentes planejados:**

* Amazon VPC e endereçamento IPv4.
* Sub-redes públicas e privadas.
* Internet Gateway (IGW).
* Tabelas de rotas.
* Security Groups e Network ACLs.
* Instâncias EC2 para testes de conectividade.
* VPC Flow Logs para monitoramento do tráfego.

A implementação inicial priorizará o aprendizado e o controle de custos, sem utilizar NAT Gateway.

> **Nota:** esta arquitetura está em planejamento. Os recursos serão documentados conforme forem implementados e validados.

## 🛠️ Tecnologias e ferramentas
